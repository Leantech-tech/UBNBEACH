# Site---Aptos

## Pontos de interesse no detalhe do imóvel

Em **Ver detalhes**, o painel **Mapa do imóvel** ocupa o espaço abaixo das regras e mostra o mapa centrado nas coordenadas cadastradas; quando o mapa incorporado não está configurado, aparece o link **Ver localização no Google Maps**. A API do catálogo não devolve latitude/longitude diretamente; o pin abre sob demanda, inclusive para imóveis com endereço oculto, conforme solicitação explícita. O endereço continua mascarado no site. O botão **Ver pontos de interesse** abre um popup; só nesse clique o servidor consulta o Google Places (New) em um raio de 10 km em linha reta a partir das coordenadas internas. A busca inclui farmácias, mercados, praias, cachoeiras, restaurantes, pizzarias, hamburguerias, cafés, padarias, parques e atrações, com filtro por categoria. Para endereços ocultos, a resposta também omite a distância de cada lugar. Sem coordenadas internas, o painel informa que a localização precisa ser cadastrada.

Configure `GOOGLE_PLACES_API_KEY` somente no servidor, após habilitar Places API (New) e faturamento no Google Cloud; essa chave não deve aparecer no navegador. Para mostrar o mapa incorporado, configure também `GOOGLE_MAPS_EMBED_API_KEY` com uma chave pública restrita ao domínio do site e à [Maps Embed API](https://developers.google.com/maps/documentation/embed/quickstart). A consulta de pontos usa até 11 buscas por abertura do popup (mais páginas para cachoeiras), o que pode gerar cobrança. O servidor limita a 5 aberturas por IP e 30 no total por hora, por instância; configure também quotas de uso no Google Cloud. Não há cache de resultados do Google. Cada busca Nearby retorna no máximo 20 lugares; mesmo com consultas por categoria, o Google não garante todos os lugares do raio. O popup sinaliza resultados limitados ou parciais e mostra a atribuição Google Maps. Para a publicação, disponibilize Termos de Uso e Política de Privacidade conforme as [políticas da API Places](https://developers.google.com/maps/documentation/places/web-service/policies).

Para ativar: (1) no [Google Cloud Console](https://console.cloud.google.com/), selecione/crie um projeto e vincule faturamento; (2) habilite Places API (New) e restrinja `GOOGLE_PLACES_API_KEY` à Places API; (3) para o mapa incorporado, habilite Maps Embed API e restrinja `GOOGLE_MAPS_EMBED_API_KEY` à Maps Embed API e aos domínios do site; (4) configure ambas no `.env` privado ao lado do executável e defina quotas para Places API. A chave do Embed é pública por natureza, mas deve permanecer restrita. Não coloque chaves privadas no repositório nem na conversa.

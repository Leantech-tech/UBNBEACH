# Site---Aptos

## Pontos de interesse no detalhe do imóvel

Em **Ver detalhes**, o painel **Mapa do imóvel** ocupa o espaço abaixo das regras e mostra sempre o pin exato em um mapa OpenStreetMap incorporado, com atribuição aos contribuidores. O link **Traçar rota no Google Maps** abre a rota de carro até o imóvel; quando disponível, o Google usa a localização atual do aparelho como origem. O mapa incorporado não exige chave ou faturamento do Google. A API do catálogo não devolve latitude/longitude como campos; o mapa usa as coordenadas internamente, inclusive para imóveis com endereço oculto, conforme solicitação explícita. O texto do endereço continua mascarado no site. O botão **Ver pontos de interesse** abre um popup; só nesse clique o servidor consulta o Google Places (New) em um raio de 10 km em linha reta a partir das coordenadas internas. A busca inclui farmácias, mercados, praias, cachoeiras, restaurantes, pizzarias, hamburguerias, cafés, padarias, parques e atrações, com filtro por categoria. Para endereços ocultos, a resposta também omite a distância de cada lugar. Sem coordenadas internas, o painel informa que a localização precisa ser cadastrada.

Configure `GOOGLE_PLACES_API_KEY` somente no servidor, após habilitar Places API (New) e faturamento no Google Cloud; essa chave não deve aparecer no navegador. A consulta de pontos usa até 11 buscas por abertura do popup (mais páginas para cachoeiras), o que pode gerar cobrança. O servidor limita a 5 aberturas por IP e 30 no total por hora, por instância; configure também quotas de uso no Google Cloud. Não há cache de resultados do Google. Cada busca Nearby retorna no máximo 20 lugares; mesmo com consultas por categoria, o Google não garante todos os lugares do raio. O popup sinaliza resultados limitados ou parciais e mostra a atribuição Google Maps. Para a publicação, disponibilize Termos de Uso e Política de Privacidade conforme as [políticas da API Places](https://developers.google.com/maps/documentation/places/web-service/policies).

Para ativar os pontos do Google: (1) no [Google Cloud Console](https://console.cloud.google.com/), selecione/crie um projeto e vincule faturamento; (2) habilite Places API (New) e restrinja `GOOGLE_PLACES_API_KEY` à Places API; (3) configure a chave somente no `.env` privado ao lado do executável e defina quotas para Places API. A rota do Google Maps usa uma Maps URL, sem chave; veja a [documentação oficial de rotas](https://developers.google.com/maps/documentation/urls/get-started). A atribuição do mapa OpenStreetMap segue a [licença e política de uso](https://www.openstreetmap.org/copyright).

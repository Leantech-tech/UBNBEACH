# Site---Aptos

## Pontos de interesse no detalhe do imóvel

Em **Ver detalhes**, o botão **Ver pontos de interesse** abre um popup. Só nesse clique o servidor consulta o Google Places (New) em um raio de 10 km em linha reta a partir das coordenadas internas do imóvel. A busca inclui farmácias, mercados, praias, cachoeiras, restaurantes, pizzarias, hamburguerias, cafés, padarias, parques e atrações, com filtro por categoria. O mapa e o pino do imóvel não aparecem. Para endereços ocultos, a resposta também omite a distância de cada lugar. Sem coordenadas internas, o popup informa que a localização precisa ser cadastrada.

Configure `GOOGLE_PLACES_API_KEY` **somente no ambiente do servidor**, após habilitar Places API (New) e faturamento no Google Cloud. A chave nunca deve entrar no HTML ou no JavaScript público. A consulta usa até 11 buscas por abertura do popup (mais páginas para cachoeiras), o que pode gerar cobrança. O servidor limita a 5 aberturas por IP e 30 no total por hora, por instância; configure também quotas de uso no Google Cloud. Não há cache de resultados do Google. Cada busca Nearby retorna no máximo 20 lugares; mesmo com consultas por categoria, o Google não garante todos os lugares do raio. O popup sinaliza resultados limitados ou parciais e mostra a atribuição Google Maps. Para a publicação, disponibilize Termos de Uso e Política de Privacidade conforme as [políticas da API Places](https://developers.google.com/maps/documentation/places/web-service/policies).

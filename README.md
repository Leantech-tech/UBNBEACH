# Site---Aptos

## Pontos de interesse no detalhe do imóvel

Em **Ver detalhes**, o link **Ver localização exata no Google Maps** abre o pin cadastrado do imóvel. A API do catálogo não devolve latitude/longitude diretamente; o pin abre sob demanda, inclusive para imóveis com endereço oculto, conforme solicitação explícita. O endereço continua mascarado no site. O botão **Ver pontos de interesse** abre um popup; só nesse clique o servidor consulta o Google Places (New) em um raio de 10 km em linha reta a partir das coordenadas internas. A busca inclui farmácias, mercados, praias, cachoeiras, restaurantes, pizzarias, hamburguerias, cafés, padarias, parques e atrações, com filtro por categoria. Para endereços ocultos, a resposta também omite a distância de cada lugar. Sem coordenadas internas, o popup informa que a localização precisa ser cadastrada.

Configure `GOOGLE_PLACES_API_KEY` **somente no ambiente do servidor**, após habilitar Places API (New) e faturamento no Google Cloud. A chave nunca deve entrar no HTML ou no JavaScript público. A consulta usa até 11 buscas por abertura do popup (mais páginas para cachoeiras), o que pode gerar cobrança. O servidor limita a 5 aberturas por IP e 30 no total por hora, por instância; configure também quotas de uso no Google Cloud. Não há cache de resultados do Google. Cada busca Nearby retorna no máximo 20 lugares; mesmo com consultas por categoria, o Google não garante todos os lugares do raio. O popup sinaliza resultados limitados ou parciais e mostra a atribuição Google Maps. Para a publicação, disponibilize Termos de Uso e Política de Privacidade conforme as [políticas da API Places](https://developers.google.com/maps/documentation/places/web-service/policies).

Para ativar: (1) no [Google Cloud Console](https://console.cloud.google.com/), selecione/crie um projeto e vincule uma conta de faturamento; (2) [habilite Places API (New) e crie uma chave](https://developers.google.com/maps/documentation/places/web-service/get-api-key) restrita a essa API; (3) configure a chave como `GOOGLE_PLACES_API_KEY` no ambiente do servidor ou no `.env` privado ao lado do executável; (4) defina quotas de uso no Google Cloud, publique o servidor e valide o popup. Não coloque a chave neste repositório nem na conversa.
